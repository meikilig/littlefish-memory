# 02 · 配置

`config.json` 放在根目录（`LITTLEFISH_ROOT` 环境变量或包所在目录的上一级）。所有键都有默认值，缺了就按默认走 —— 想改哪一项才写哪一项。模板见 `config.example.json`。

## 顶层

| 键 | 默认 | 说明 |
|---|---|---|
| `character` | `test` | 角色名。**换角色 = 换库路径**（`data/persona/<character>/littlefish.db`） |
| `owner.qq` | `""` | 主人的 QQ 号。空着就等于"没有主人"，主人相关的加权（私聊 +42）不会生效 |
| `owner.label` | `主人` | 注入块和日志里怎么称呼 |

## memory

| 键 | 默认 | 说明 |
|---|---|---|
| `inject_max_chars.qq` | 2200 | 每轮注入的硬预算（字）。装不下就截断，优先保 `<recall>` 与高优先桶 |
| `inject_max_chars.bili` | 2000 | B站场景的预算 |
| `room_max_chars` | 320 | `<room>`（本窗口近期气口）占多少字 |
| `rooms_active_hours` | 12 | 多久内有过动静的窗口才列进 `<rooms>` |
| `rooms_max` | 3 | 最多列几个窗口（只给名字 + 气口，不给原话） |
| `max_records` | 600 | 活跃记忆软上限，超了先淘汰低分 |
| `daily_hour` | 4 | 每天几点跑衰减（`decay_once`） |
| `decay_per_day` | 1 | 一次衰减掉几档 clarity |
| `decay_min_age_days` | 1 | 至少多少天前的记忆才参与衰减 |
| `fuzzy_after_days` | 7 | 多少天不再被提起就转"模糊" |
| `forget_after_days` | 60 | 多少天且没被想起过就归档（`archived=1`，不物理删） |
| `min_owner_importance` | 65 | 主人说的话至少多少分才强制留住 |
| `first_window_days` | 30 | "最初的事"只看最近多少天内的第一次 |
| `first_slots` | 3 | "最初的事"最多留几条 |
| `maintain_interval_min` | 10 | 维护任务间隔（分钟） |
| `auto_recall` | true | 关掉就完全不检索（`on_message` 直接返回空） |
| `recall_topn` | 3 | 一次最多"想起"几条 |
| `recall_min_hits` | 2 | 检索词与记忆至少重合几个 bigram 才算命中 |
| `recall_same_topic_hours` | 24 | 同一条记忆多久内只算一次被想起（防刷升级） |
| `recall_block_chars` | 200 | `<recall>` 段的字数上限，0 = 关 |
| `promote_hits.l2/l3/l4` | 1 / 3 / 8 | 升到 L2/L3/L4 需要累计被想起几次 |
| `hold_days.l2/l3` | 7 / 14 | 升级的时间窗：超过这么多天没被想起就不升 |
| `l1_keep_days` | 14 | L1 躺多久压成一行进本子 |

## privacy

| 键 | 默认 | 说明 |
|---|---|---|
| `redact` | true | 注入前是否打码隐私文本 |
| `isolation.enabled` | true | 场景隔离总开关。**注意：它对私聊对私聊那条硬规矩无效** |
| `isolation.private_in_group` | false | 群聊里能不能看到主人的私聊记忆 |
| `isolation.cross_group` | false | 群 A 能不能看到群 B 的记忆 |
| `isolation.group_in_private` | false | 私聊里能不能看到群聊的记忆 |

> 私聊 ↔ 私聊：`conversation_key` 不同就一律不可见，**没有任何开关能放宽**。这条是设计红线，不是配置项。

## archive

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 是否在夜里归页 |
| `open_max` | 1200 | 一次翻页最多回多少字（超出给头尾两段） |
| `catalog_topn` | 5 | 目录最多列几页 |
| `hour` / `minute` | 23 / 30 | 每天几点归档（要赶在流水被清之前） |

## 跑 demo 用不用改配置？

不用。`demo.py` 自己会写一份临时的 `config.json`（`character=demo`、`owner.qq=10001`），跑完连同临时库一起删掉。
